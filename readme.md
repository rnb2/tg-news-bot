# Telegram News Bot

Бот для автоматического сбора и публикации новостей в Telegram канал.

## Возможности
* Собирает новости из RSS-лент (IT, Авто, Наука, Кино и др.).
* Фильтрует дубликаты (не постит одно и то же дважды).
* Публикует посты с заголовком, кратким описанием, хэштегом категории и ссылкой.
* Работает по расписанию: 5 раз в день (09:00, 12:00, 15:00, 18:00, 21:00).

## Установка и Настройка

### 1. Требования
* Python 3.8 или выше.
* Установленные библиотеки (см. `requirements.txt`).

### 2. Установка зависимостей
Выполните команду в папке с ботом:
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` (если его нет) и добавьте свои данные:
```ini
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHANNEL_ID=@ваш_канал
```
* **Token:** Получите у [@BotFather](https://t.me/BotFather).
* **Channel ID:** Юзернейм канала (начинается с `@`) или ID (начинается с `-100`). Бот должен быть администратором канала!

### 4. Настройка источников новостей
Список RSS-лент находится в файле `sources.py`.
Вы можете редактировать его, добавляя или удаляя ссылки.

Пример структуры:
```python
RSS_SOURCES = {
    "IT": ["https://habr.com/rss/news/"],
    "Наука": ["https://naked-science.ru/feed"],
}
```
**Важно:** После изменения `sources.py` бота необходимо **перезапустить**, чтобы изменения вступили в силу.

## Запуск

### Запуск вручную (для проверки)
```bash
python bot.py
```
*При первом запуске бот сразу опубликует один пост для проверки.*

### Запуск в фоновом режиме (Windows)
```powershell
Start-Process -NoNewWindow -FilePath "C:\Users\buduk\AppData\Local\Programs\Python\Python313\python.exe" -ArgumentList "bot.py"
```
*(Убедитесь, что python добавлен в PATH, или используйте полный путь к python.exe)*

## Управление

* **Остановка:** Найдите процесс `python.exe` в Диспетчере задач и завершите его.
* **История:** Список опубликованных ссылок хранится в `posted_news.json`. Если хотите сбросить историю ("забыть", что постили), просто удалите этот файл.

## Структура файлов
* `bot.py` — Основной код бота.
* `sources.py` — Настройки источников (RSS лент).
* `.env` — Токены и секреты.
* `requirements.txt` — Список библиотек.
* `posted_news.json` — История публикаций (создается автоматически).
